# 0002 — Editing for John (CMS)

Status: **open — blocks launch, not the scaffold**
Date: 2026-09-12
Relates to: `docs/02-project-structure.md` §0, ADR 0001

## Context

Moving off Wix removes John's ability to edit his own site. The options as framed
in `docs/02-project-structure.md` §0:

| Option | What John can edit | Ongoing load |
|---|---|---|
| A. Repo + git-based CMS (Keystatic / Sveltia) | Blog posts, testimonials, FAQs, prices, copy — via a `/admin` UI that commits markdown | Low |
| B. Repo only | Nothing | Every typo is a developer task |
| C. Repo + hosted CMS (Sanity / Contentful) | Same as A, nicer UI | Low, plus a second vendor |

## Decision

Not yet made. The content model in `src/content.config.ts` is written to suit
option A — plain markdown with flat, human-editable frontmatter, no computed
fields, no cross-file math — so choosing A later requires no schema migration.
Choosing C would.

## Consequences

- Milestone 5 (handoff) cannot be scoped until this is decided.
- Keep frontmatter editable by a human in a web form: strings, enums, string
  arrays, booleans, numbers. Nothing that requires knowing the repo.
- Revisit before the About/Contact milestone, so John gets a walkthrough on real
  content rather than examples.
